\- Retrieve relevant information from the project knowledge base.

\- Avoid inventing information when the knowledge base does not contain an answer.

\- Generate class reflections using student-provided notes.

\- Maintain a prompt and activity log.

\- Retrieve relevant corporate-startup news.

\## 4. Test 2 — Unsupported Information / Hallucination Control



\### Question



> What was the exact revenue generated by Panasonic Co.lab Studio in 2026?



\### Expected Behavior



The system should not invent a revenue figure because the knowledge base does not contain this information.



\### Observed Result



Agent Tutor stated that the provided material did not contain the exact revenue figure and did not generate a fictional number.

\*\*PASS\*\*

\## 5. Test 3 — Panasonic Knowledge / RAG



\### Question



> Name some startups that Panasonic has collaborated with according to the project knowledge base.



\### Expected Behavior



The system should retrieve the Panasonic knowledge base and identify verified examples.



\### Observed Result



The system retrieved `panasonic\_notes.txt` with strong similarity scores and identified examples including:



\- Portl

\- Sensio

\- Red Health

\- Respirer Living Sciences



The retrieval test also successfully returned information about Co.lab Studio by IGNITION.



\### Result



\*\*PASS\*\*



\### Limitation Observed



The LLM incorrectly treated Co.lab Studio by IGNITION as a startup in part of the generated response. The knowledge base itself distinguishes the programme from the startups.



This indicates that retrieval was successful, but the LLM can occasionally misinterpret retrieved information.

\## 8. Test 6 — Fortnightly Corporate-Startup News



\### Expected Behavior



The system should:



\- Search for recent Panasonic startup/co-creation news.

\- Apply the 14-day filter.

\- Remove duplicate articles.

\- Display the article source and date.

\- Provide a clearly labelled AI interpretation.

\- Link to the original article.



\### Observed Result



The system successfully retrieved relevant Panasonic startup/co-creation news and displayed the results in the Streamlit interface.



The AI interpretation is explicitly labelled and the interface warns that it is based on the headline rather than verified full article content.



\### Result



\*\*PASS\*\*



\### Limitation Observed



Because the current news retrieval uses headline-level information, the AI interpretation cannot reliably provide detailed article facts unless those facts are available in the retrieved information.

\## 9. Overall Evaluation



The evaluation shows that Agent Tutor successfully combines:



\- Local LLM inference

\- Embeddings

\- Retrieval-Augmented Generation

\- Course knowledge

\- Panasonic project knowledge

\- Class Reflection

\- Prompt logging

\- Student notes

\- Corporate-startup news retrieval

\- Streamlit interface



The system also demonstrates an important grounding behavior by refusing to provide unsupported information when a requested fact is not available in the knowledge base.



\---



\## 10. Known Limitations



The current system has several limitations:



1\. The LLM may occasionally add reasonable-sounding information beyond the retrieved evidence.

2\. News interpretation is based primarily on headline-level information.

3\. The current knowledge base is limited to the material that has been deliberately added.

4\. Retrieval similarity does not guarantee that every generated statement is factually correct.

5\. The system does not replace verified external research or human judgment.



\---



\## 11. Conclusion



The evaluation indicates that Agent Tutor is functioning as a course-specific RAG-based AI tutor.



The system can retrieve course and project knowledge, generate grounded responses, support class reflection, maintain an interaction log, and provide relevant corporate-startup news.



The testing also identified limitations in LLM interpretation, which will be considered when presenting the system and its future improvements.
